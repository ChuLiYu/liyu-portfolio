Google Tasks MCP

公開早期版本

自架的 MCP server，讓 Claude 把口語轉成 Google Tasks，並刻意限制 AI agent 能造成的破壞。

  • 在使用者自己的電腦上、以使用者自己的 Google OAuth client 執行；沒有託管後端，本機不保存任務內容。
  • 預設唯讀、不提供刪除工具，可選擇逐筆核准寫入。
  • 任務在讀取後若已被變更就拒絕覆寫；寫入結果不明時不會靜默重試。
  • 以 ./setup.sh 引導非工程背景的使用者完成設定。

已驗證：CI 通過；已在 macOS 搭配 Claude Desktop 與 Claude Web 測試。

Docker Desktop、Linux 與 ChatGPT 尚未確認。

Raft-Recovery

系統實作學習專案

以 Go 開發的複寫式任務佇列，分三階段完成：本機持久化執行、遠端 gRPC worker，再到自行實作的 Raft。

  • 自行實作 Raft：隨機選舉、持久化 term／vote／log、多數複寫、衝突修復、快照、日誌壓縮與 InstallSnapshot 追趕。
  • 寫入必須經多數節點提交並套用到本機狀態機後才回傳成功。
  • 以嘗試編號（attempt fencing）驗證回覆，過期 worker 無法改動已重新指派的任務。
  • 任務 ID 在重試、壓縮與重啟後仍保持冪等；具校驗碼的 WAL、逾時與 dead letter。

已驗證：CI 執行 race 檢查與 go vet；單元、整合與跨容器測試涵蓋 leader 失效、磁碟復原與過期 worker 回覆。

範圍：單一 Linux VM 上的固定三節點叢集；worker 執行語意為至少一次。

Arc Sentinel

原型

唯讀的 EVM 錢包活動索引器與監控 API，具規則式警示。

  • 索引進度與索引資料在同一個交易中提交；以衝突處理避免重複資料。
  • 確認區塊緩衝與有上限的追趕批次。
  • RPC 退避重試、獨立處理限流，並支援備援供應商。
  • 預算、收款方與異常規則；寫入端點以雜湊 API key 保護。

已驗證：154 項測試通過，含對臨時 PostgreSQL 的整合測試；依賴弱點掃描無已知問題（2026 年 11 月）。

下一步：鏈重組回滾，以及多個索引器之間的單一寫入者租約。

AlphaPulse

作品集示範

結合 REST API、Airflow 資料管線與有邊界 LLM 工具呼叫 agent 的金融資料應用。

  • JWT 驗證並區分讀寫權限；API key 以摘要儲存；具權限提升的回歸測試。
  • 價格與回測的現金、成本計算使用 Decimal 型別。
  • LLM agent 具工具白名單、嚴格參數與執行預算；數值檢查由程式執行，而非交給模型。

已驗證：36 項容器化整合測試通過；前端 npm audit 已知弱點由 35 降為 0。

託管示範目前離線；部分端點使用模擬資料。
