Google Tasks MCP

Public early release

A self-hosted MCP server that lets Claude turn natural language into Google Tasks, designed to limit what an AI agent can break.

  • Runs on the user's machine with their own Google OAuth client; no hosted backend, and task content is not stored locally.
  • Read-only by default, no delete tool, optional per-write approval.
  • Refuses to overwrite a task changed since it was read; no silent retry after an unknown write result.
  • Guided ./setup.sh onboarding for non-developers.

Verified: CI passing; tested on macOS with Claude Desktop and Claude Web.

Docker Desktop, Linux and ChatGPT are not yet confirmed.

Raft-Recovery

Educational systems project

A replicated job queue in Go, built in three stages: durable local execution, remote gRPC workers, then a custom Raft implementation.

  • Custom Raft: randomized elections, persistent term/vote/log, majority replication, conflict repair, snapshots, log compaction and InstallSnapshot catch-up.
  • A write returns success only after majority commit and local state-machine application.
  • Attempt-fenced acknowledgements stop a stale worker from changing a reassigned job.
  • Job IDs stay idempotent across retries, compaction and restarts; checksummed WAL, timeouts and dead letters.

Verified: CI runs race checks and go vet; unit, integration and cross-container tests cover leader loss, disk recovery and stale worker acknowledgements.

Scope: static three-node cluster on one Linux VM; worker execution is at least once.

Arc Sentinel

Prototype

A read-only EVM wallet activity indexer and monitoring API with rule-based alerts.
